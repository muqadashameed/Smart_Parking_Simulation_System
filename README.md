# Smart Parking Simulation System

This project is an AI-powered Smart Parking Management System that combines data analysis, machine learning, live 3D simulation, and an interactive Streamlit dashboard.

## Live Dashboard

Dashboard URL: https://smart-parking-dashboard.streamlit.app

## Project Phases

### Phase 1: EDA and Feature Engineering
- Dataset cleaning
- Exploratory data analysis
- Feature selection
- Occupancy pattern analysis

### Phase 2: Machine Learning Models
- Random Forest Classifier
- XGBoost Classifier
- Occupancy prediction: Occupied vs Available
- Model comparison using accuracy, precision, and F1-score

### Phase 3: 3D Simulation
- Live browser-based parking simulation
- Cars enter, park, and exit
- Red and green sensors show occupied and available slots
- Entry and exit routes
- Real-time occupancy metrics
- 360-degree camera controls

### Phase 4: Streamlit Dashboard
- Overview page
- Live simulation page
- EDA insights
- Prediction tool
- Model comparison page

## Final Outcome

The final system provides one dashboard link where users can view analysis, prediction, model comparison, and live 3D parking simulation.
